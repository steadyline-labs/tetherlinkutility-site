Windows, macOS और iOS पर SOCKS5 प्रॉक्सी कैसे सेट करें

प्रकाशित 18 सितंबर, 2026 · अपडेट 23 अक्टूबर, 2026

Tether Link Utility आपके Android फ़ोन पर एक लोकल SOCKS5 प्रॉक्सी चलाता है। दूसरे डिवाइस ऐप के बनाए Wi-Fi से जुड़कर इसे इस्तेमाल करते हैं। Windows PC या Mac पर एक छोटी फ़ाइल आपके लिए सब सेट कर देती है: यह sing-box इंस्टॉल करके चलाती है, ताकि पूरा कंप्यूटर फ़ोन का इंटरनेट इस्तेमाल करे। iOS पर एक हल्का ऐप चाहिए। यहां हर प्लेटफ़ॉर्म को जोड़ने का तरीका बताया गया है।

शुरू करने से पहले

इसी क्रम में करें। हो सकता है फ़ोन के Wi-Fi पर अपना इंटरनेट न हो (वह सिर्फ़ फ़ोन के प्रॉक्सी तक पहुंचाता है), इसलिए पहले सब कुछ इंस्टॉल कर लें।

  1. पहले ज़रूरी चीज़ें इंस्टॉल करें, जब तक आपके डिवाइस पर उसका सामान्य इंटरनेट चल रहा है:
    • iPhone या iPad: App Store से Potatso (फ्री) या Shadowrocket (पेड)।
    • Windows कंप्यूटर: सेटअप फ़ाइल (देखें Windows)। यह आपके लिए sing-box इंस्टॉल करके चलाती है, ताकि सभी ऐप्स काम करें।
    • Linux कंप्यूटर: सभी ऐप्स के लिए sing-box (देखें Linux), या सिर्फ़ उस ब्राउज़र के लिए firefox.com से Firefox।
    • Mac: हमारी स्क्रिप्ट (देखें macOS)। यह आपके लिए sing-box इंस्टॉल करके चलाती है, ज़रूरत हो तो फ़ोन के ज़रिए भी।

    उस डिवाइस पर इंटरनेट नहीं है? उसे कुछ मिनट के लिए किसी दूसरे Wi-Fi (घर, ऑफ़िस, कैफ़े) से जोड़ें और वहीं से डाउनलोड करें। Windows PC सेटअप फ़ाइल फ़ोन से भी ले सकता है: फ़ाइल फ़ोन पर डाउनलोड करें और Bluetooth या USB केबल से PC पर भेजें।

  2. शेयर करने वाले फ़ोन पर Tether Link Utility खोलें और START SHARING दबाएं। पहली बार ऐप One permission is needed दिखाता है: Allow दबाएं, फिर फ़ोन की कनेक्शन अनुरोध (Connection request) विंडो में ठीक है (OK) दबाएं।
  3. ऐप पूछता है Which device will use this phone's internet? अपना डिवाइस चुनें: Android phone or tablet, Windows computer, iPhone or iPad, Mac, Linux या Other (TV, game console…)।
  4. Windows PC या Mac के लिए ऐप पहले डाउनलोड करने वाली फ़ाइल दिखाता है। फ़ोन या दूसरे डिवाइस के लिए ऐप पूछता है कि उस पर ज़रूरी चीज़ पहले से है या नहीं, जैसे Is Tether Link Utility on the other phone? Yes, it's installed, No, but it has internet या No, and it has no internet दबाएं, ऐप इंस्टॉल करने का तरीका दिखाएगा। अभी फ़ोन के Wi-Fi से न जुड़ें।
  5. इसके बाद अपने डिवाइस पर ऐप में Name के नीचे दिखे Wi-Fi से, Password के नीचे दिखे पासवर्ड के साथ जुड़ें। अगर "No internet" दिखे, तो यह सामान्य है।
  6. ऐप में दिखी दो वैल्यू (SOCKS Host या Server, और Port) नीचे अपने डिवाइस के सेटअप में डालें। ऐप की स्क्रीन अपने आप इंतज़ार करती है और डिवाइस जुड़ते ही आगे बढ़ जाती है।

पोर्ट के बारे में: ऐप पोर्ट को सेव रखता है, इसलिए हर डिवाइस पर इसे सिर्फ़ एक बार डालना होता है। पोर्ट तभी बदलता है जब फ़ोन का कोई दूसरा ऐप उसे इस्तेमाल करने लगे, और ऐसा होने पर ऐप आपको बताता है। अपना पोर्ट चुनने के लिए Port वाली लाइन पर Edit दबाएं और 1024 से 65535 के बीच कोई नंबर डालें (1024 से 32767 के बीच टकराव की संभावना कम होती है)। चुना गया पोर्ट खाली हो तो वह आपके लिए तब तक रिज़र्व रहता है जब तक कोई दूसरा ऐप उसे इस्तेमाल न करने लगे।

फ़ोन का अपना हॉटस्पॉट इस्तेमाल करना

अगर ऐप के बजाय आप फ़ोन का सिस्टम हॉटस्पॉट खुद ऑन करते हैं (Android पर Mobile Hotspot, iPhone पर Personal Hotspot), तो ऐप में Add hotspot Wi-Fi details पर टैप करें और हॉटस्पॉट का नाम और पासवर्ड एक बार सेव करें। ये सिर्फ़ आपके डिवाइस पर स्टोर होते हैं और ऐप आपका हॉटस्पॉट नहीं बदलता। ये डिटेल्स QR कोड में जोड़ दी जाती हैं, ताकि दूसरे डिवाइस उसे स्कैन करके नेटवर्क से जुड़ सकें। iPhone पर पासवर्ड Settings > Personal Hotspot में मिलता है। जब Android ऐप अपने आप अपना हॉटस्पॉट शुरू करता है, तब आप यह स्टेप छोड़ सकते हैं।

Windows

सुझाया गया: सेटअप फ़ाइल (सभी ऐप्स)

एक छोटी फ़ाइल PC के सभी ऐप्स के लिए पूरा सेटअप कर देती है, DNS समेत। यह ऐप में दिखे IP और पोर्ट पूछती है, जांचती है कि फ़ोन जवाब दे रहा है, sing-box को उसके आधिकारिक GitHub पेज से एक बार डाउनलोड करती है (SHA256 हैश से जांचा हुआ) और कनेक्ट कर देती है।

TLU-Windows-Setup.cmd डाउनलोड करें

  1. जब तक PC पर उसका अपना इंटरनेट चल रहा है, ऊपर वाली फ़ाइल डाउनलोड कर लें। अगर Edge कहे कि फ़ाइल could harm your device, तो फ़ाइल के नाम के नीचे Keep पर क्लिक करें। नहीं दिख रहा? Edge में ऊपर दाईं ओर डाउनलोड वाले तीर पर क्लिक करें। PC पर डाउनलोड के लिए इंटरनेट नहीं है? फ़ाइल फ़ोन पर डाउनलोड करें और Bluetooth या USB केबल से PC पर भेजें।
  2. फ़ोन के Wi-Fi से जुड़ें और ऐप में शेयरिंग चालू करें।
  3. फ़ाइल पर डबल-क्लिक करें। अगर Windows पूछे Are you sure you want to run this software?, तो Run पर क्लिक करें। अगर इसकी जगह Windows protected your PC दिखे, तो More info और फिर Run anyway पर क्लिक करें। जब Windows बदलाव की अनुमति मांगे, तो Yes पर क्लिक करें (उसमें Windows PowerShell लिखा होगा, यही फ़ाइल है)।
  4. सुझाया गया IP इस्तेमाल करने के लिए Enter दबाएं (या ऐप वाला IP लिखें), फिर पोर्ट लिखें।
  5. जब Connected. Keep this window open. दिखे, तो काम हो गया। रोकने के लिए विंडो बंद करें। अगली बार डेस्कटॉप पर TLU connect पर डबल-क्लिक करें।

यह फ़ाइल सादा टेक्स्ट है: आप इसे Notepad में खोलकर हर कदम पढ़ सकते हैं। यह कहीं कुछ नहीं भेजती। हाथ से करना चाहते हैं? नीचे दिए कदम देखें।

Windows Settings > Proxy इस्तेमाल न करें। यह इस ऐप के साथ काम नहीं करता। नीचे दिए विकल्पों में से कोई एक इस्तेमाल करें।

खुद से: sing-box से सभी ऐप्स के लिए

ऊपर वाली सेटअप फ़ाइल ये स्टेप्स आपके लिए करती है। खुद से करना हो तो sing-box (ओपन सोर्स, सक्रिय रूप से मेंटेन्ड) को TUN मोड में इस्तेमाल करें:

  1. जब तक PC में इंटरनेट है, github.com/SagerNet/sing-box/releases खोलें। वह फ़ाइल डाउनलोड करें जिसका नाम windows-amd64.zip पर खत्म होता है (Snapdragon या Surface Pro X: windows-arm64.zip)। उस पर राइट-क्लिक करें, Extract All चुनें, फिर Extract पर क्लिक करें।
  2. Notepad खोलें और नीचे दिए sing-box कॉन्फ़िग बॉक्स का टेक्स्ट पेस्ट करें। PHONE_IP (यह दो जगह है) और PHONE_PORT की जगह ऐप में दिखे नंबर लिखें। File, फिर Save as पर क्लिक करें। sing-box फ़ोल्डर खोलें (जिसमें sing-box.exe है), Save as type में All files चुनें, नाम config.json रखें और Save पर क्लिक करें।
  3. Start बटन पर राइट-क्लिक करें और Terminal (Admin) चुनें। Yes पर क्लिक करें।
  4. विंडो में cd लिखें और एक स्पेस दें। File Explorer से sing-box फ़ोल्डर को खींचकर विंडो में छोड़ें, फिर Enter दबाएं। अगर खींचने पर कुछ न दिखे: sing-box फ़ोल्डर पर राइट-क्लिक करें, Copy as path चुनें, विंडो में क्लिक करें, Ctrl+V दबाएं, फिर Enter।
  5. .\sing-box.exe run --config config.json लिखें और Enter दबाएं। यह विंडो खुली रहने दें।
  6. sing-box started दिखने तक इंतज़ार करें। लाइनें चलती रहेंगी; यह सामान्य है।

सिर्फ़ ब्राउज़र: Firefox (किसी एक्सटेंशन की ज़रूरत नहीं)

  1. Firefox में Settings खोलें, ऊपर के सर्च बॉक्स में proxy लिखें और Configure proxy पर क्लिक करें।
  2. खुद से प्रॉक्सी कॉन्फ़िगर करें (Manual proxy configuration) चुनें।
  3. फ़ोन का IP SOCKS होस्ट (SOCKS Host) में डालें, पोर्ट पोर्ट (Port) में, और SOCKS v5 चुनें।
  4. SOCKS v5 उपयोग करने पर स्थानापन्न डीएनएस (Proxy DNS when using SOCKS v5) चेक करें, ताकि DNS लुकअप भी प्रॉक्सी से जाएं, फिर OK पर क्लिक करें।
  5. Firefox में कोई भी वेबसाइट खोलें। फ़ोन का इंटरनेट सिर्फ़ Firefox इस्तेमाल करता है, कंप्यूटर के बाकी ऐप्स नहीं।

सिर्फ़ ब्राउज़र: Chrome या Edge, FoxyProxy के ज़रिए

  1. Chrome Web Store से FoxyProxy एक्सटेंशन इंस्टॉल करें।
  2. एक नया प्रॉक्सी जोड़ें: टाइप SOCKS5, host = फ़ोन का IP, port = ऐप में दिखाया गया पोर्ट।
  3. टूलबार आइकन से FoxyProxy को उस प्रॉक्सी पर स्विच करें।

macOS

सुझाया गया: हमारी स्क्रिप्ट से सभी ऐप्स (sing-box)

हमारी स्क्रिप्ट आपके लिए sing-box इंस्टॉल करके TUN मोड में चलाती है, ताकि हर ऐप DNS सहित फ़ोन का इंटरनेट इस्तेमाल करे।

सबसे आसान तरीका: हमारी स्क्रिप्ट डाउनलोड करें

और कुछ इंस्टॉल नहीं करना है: Homebrew की ज़रूरत नहीं। पहली बार स्क्रिप्ट sing-box को उसके आधिकारिक GitHub पेज से डाउनलोड करती है (SHA256 hash से जांचा जाता है), और अगर Mac का अपना इंटरनेट न हो तो फ़ोन के ज़रिए। यह ऐप में दिखा IP और पोर्ट पूछती है और बैकग्राउंड में चलती रहती है (Terminal विंडो छोटी हो जाती है और कोई दिक्कत होने पर ही वापस आती है)।

tlu-mac-tunnel.zip डाउनलोड करें

  1. Safari zip को आपके लिए खोल देता है। अगर आपको .zip फ़ाइल दिखे, तो उस पर डबल-क्लिक करें। Downloads में tlu-mac-tunnel फ़ोल्डर आ जाएगा।
  2. फ़ोन के Wi-Fi से जुड़ें और ऐप में शेयरिंग चालू करें।
  3. Command + Space दबाएं, Terminal टाइप करें, Return दबाएं।
  4. cd ~/Downloads/tlu-mac-tunnel टाइप करें और Return दबाएं।
  5. bash tlu-mac-tunnel.sh टाइप करें और Return दबाएं।
  6. ऐप में दिखा IP और पोर्ट टाइप करें, हर एक के बाद Return दबाएं। अगली बार यह पूछेगी Connect to IP:port? (y/n): वही इस्तेमाल करने के लिए y टाइप करके Return दबाएं, या नए टाइप करने के लिए n।
  7. अपने Mac का पासवर्ड टाइप करें और Return दबाएं। टाइप करते समय कुछ नहीं दिखता; यह सामान्य है।
  8. जब Connected. दिखे, तो हो गया। विंडो छोटी हो जाती है और कनेक्शन चलता रहता है।

बंद करने के लिए: Dock में Terminal पर क्लिक करें, फिर उसकी विंडो में Control + C दबाएं। ऐप में शेयरिंग बंद करने से पहले इसे यहां बंद करें; वरना जब तक आप इसे बंद नहीं करते, Mac पर इंटरनेट नहीं रहेगा।

स्क्रिप्ट सादा टेक्स्ट है: आप इसे TextEdit में खोलकर हर स्टेप पढ़ सकते हैं। यह कहीं कुछ नहीं भेजती। यह TLU के लिए तैयार किया गया sing-box सेटअप है; अगर आप sing-box जानते हैं, तो उसे सीधे भी इस्तेमाल कर सकते हैं।

इसे काम करते हुए देखें

Mac पर स्क्रिप्ट चलते हुए: फ़ोन अपना मोबाइल डेटा शेयर करता है, कनेक्शन के ज़रिए 1GB की टेस्ट फ़ाइल डाउनलोड होती है, और ऐप का काउंटर फ़ोन से होकर गया ट्रैफ़िक दिखाता है।

या इसे हाथ से सेटअप करें:

  1. जब तक Mac पर इंटरनेट है, github.com/SagerNet/sing-box/releases खोलें और वह फ़ाइल डाउनलोड करें जिसका नाम darwin-arm64.tar.gz पर खत्म होता है (Apple चिप वाला Mac, M1 या नया) या darwin-amd64.tar.gz (Intel Mac)। Downloads में उस पर डबल-क्लिक करके खोलें। (Homebrew पहले से है? brew install sing-box भी चलेगा।)
  2. TextEdit खोलें और पहले Format › Make Plain Text पर क्लिक करें (वरना फ़ाइल काम नहीं करेगी)। नीचे दिए sing-box कॉन्फ़िग बॉक्स का टेक्स्ट पेस्ट करें और PHONE_IP (यह दो जगह है) और PHONE_PORT की जगह ऐप में दिखे नंबर लिखें। File › Save पर क्लिक करें, नाम config.json रखें, sing-box फ़ोल्डर चुनें (जिसमें sing-box है) और Save पर क्लिक करें। अगर TextEdit पूछे, तो Use .json पर क्लिक करें।
  3. Command + Space दबाएं, Terminal टाइप करें, Return दबाएं। cd और एक स्पेस टाइप करें, sing-box फ़ोल्डर को विंडो में खींचकर छोड़ें, फिर Return दबाएं।
  4. xattr -c sing-box टाइप करें और Return दबाएं (इससे macOS डाउनलोड की गई फ़ाइल चला पाता है)। फिर sudo ./sing-box run --config config.json टाइप करें और Return दबाएं (Homebrew के साथ: sudo sing-box run --config config.json)। अपने Mac का पासवर्ड टाइप करें और Return दबाएं; टाइप करते समय कुछ नहीं दिखता।
  5. sing-box started दिखने तक रुकें और विंडो खुली छोड़ दें। बंद करने के लिए ऐप में शेयरिंग बंद करने से पहले इसी विंडो में Control + C दबाएं।
  6. अगर नीचे वाली बिल्ट-इन SOCKS Proxy सेटिंग ऑन थी तो उसे बंद कर दें, sing-box का TUN मोड इसे पूरी तरह बदल देता है।

दूसरा तरीका: बिल्ट-इन प्रॉक्सी सेटिंग (कम ऐप्स)

  1. System Settings → Wi-Fi खोलें।
  2. फ़ोन वाले Wi-Fi के बगल में Details… पर क्लिक करें, फिर Proxies पर।
  3. SOCKS proxy ऑन करें, फ़ोन का IP एड्रेस और पोर्ट डालें, फिर OK पर क्लिक करें।
  4. Safari में कोई भी वेबसाइट खोलें।

किसी थर्ड-पार्टी ऐप की ज़रूरत नहीं, पर ध्यान दें macOS की native SOCKS सेटिंग DNS को प्रॉक्सी से रूट नहीं करती, और कुछ ऐप्स सिस्टम प्रॉक्सी सेटिंग को नहीं मानते। DNS सहित पूरी कवरेज के लिए ऊपर वाली स्क्रिप्ट इस्तेमाल करें।

sing-box कॉन्फ़िग (Windows, macOS और Linux के लिए काम करता है, बस IP/पोर्ट बदलें)। interface_name खाली छोड़ दें ताकि यह अपने आप एक उपलब्ध इंटरफ़ेस चुन ले:

{
  "dns": {
    "servers": [
      { "type": "udp", "tag": "remote", "server": "8.8.8.8", "detour": "phone-socks5" },
      { "type": "local", "tag": "local", "detour": "direct" }
    ],
    "final": "remote"
  },
  "inbounds": [
    { "type": "tun", "tag": "tun-in", "address": ["172.19.0.1/30"], "mtu": 1500,
      "auto_route": true, "strict_route": true, "stack": "system" }
  ],
  "outbounds": [
    { "type": "socks", "tag": "phone-socks5", "server": "PHONE_IP", "server_port": PHONE_PORT, "version": "5" },
    { "type": "direct", "tag": "direct" }
  ],
  "route": {
    "rules": [ { "ip_cidr": ["PHONE_IP/32"], "outbound": "direct" } ],
    "final": "phone-socks5",
    "auto_detect_interface": true,
    "default_domain_resolver": "remote"
  }
}

PHONE_IP और PHONE_PORT दोनों को ऐप में दिखाए गए वैल्यू से बदलें (और PHONE_IP/32 रूट रूल भी, यह लाइन टनल को अपने ही फ़ोन कनेक्शन को खुद के ज़रिए रूट करने से रोकती है)। ऐप के लेटेस्ट वर्शन में SOCKS5 UDP ASSOCIATE सपोर्ट है, इसलिए QUIC/HTTP3 और DNS भी प्रॉक्सी से जाते हैं।

Linux

विकल्प A: Firefox

  1. Firefox में Settings खोलें, सर्च बॉक्स में proxy लिखें, Configure proxy पर क्लिक करें और खुद से प्रॉक्सी कॉन्फ़िगर करें (Manual proxy configuration) चुनें।
  2. फ़ोन का IP SOCKS होस्ट (SOCKS Host) में डालें, पोर्ट पोर्ट (Port) में, और SOCKS v5 चुनें।
  3. SOCKS v5 उपयोग करने पर स्थानापन्न डीएनएस (Proxy DNS when using SOCKS v5) चेक करें और OK पर क्लिक करें।

विकल्प B: sing-box से सभी ऐप्स के लिए

  1. फ़ोन के Wi-Fi से जुड़ने से पहले sing-box अपने डिस्ट्रीब्यूशन के पैकेज से या GitHub releases से इंस्टॉल करें।
  2. ऊपर दिया कॉन्फ़िग config.json के तौर पर सेव करें, IP/पोर्ट को ऐप में दिखाए गए से बदल दें।
  3. root के तौर पर चलाएं: sudo sing-box run --config config.json

iOS

विकल्प A: Potatso (फ्री)

  1. Potatso खोलें और + दबाएं।
  2. ऐप में दिखी दो वैल्यू (Server और Port) के साथ एक SOCKS5 सर्वर जोड़ें और सेव करें।
  3. Potatso में स्विच ऑन करें। iPhone पूछे तो Allow दबाएं। इसी तरह Potatso ट्रैफ़िक को SOCKS5 प्रॉक्सी तक भेजता है, क्योंकि iOS में macOS जैसी सिस्टम-वाइड SOCKS5 सेटिंग नहीं होती।

विकल्प B: Shadowrocket (पेड, एक बार की खरीद)

  1. Shadowrocket खोलें और ऊपर दाईं तरफ़ + बटन दबाएं।
  2. टाइप Socks5 चुनें।
  3. फ़ोन का IP एड्रेस के तौर पर और ऐप में दिखाया गया पोर्ट डालें।
  4. सेव करें, फिर कनेक्ट करने के लिए ऊपर टॉगल दबाएं।

DNS टिप: पक्का करें कि DNS क्वेरी भी प्रॉक्सी से जाएं। Firefox में SOCKS v5 उपयोग करने पर स्थानापन्न डीएनएस (Proxy DNS when using SOCKS v5) चेक करें; Shadowrocket यह डिफ़ॉल्ट रूप से करता है। macOS की System Settings वाली SOCKS सेटिंग DNS को प्रॉक्सी से नहीं भेजती, इसलिए Mac पर पूरी कवरेज के लिए हमारी स्क्रिप्ट इस्तेमाल करें। ऊपर बताया गया sing-box का TUN मोड यह अपने आप संभालता है, क्योंकि यह हर ऐप की सेटिंग पर निर्भर रहने के बजाय बाकी ट्रैफ़िक के साथ DNS भी प्रॉक्सी से भेजता है।

TV और गेम कंसोल

ज़्यादातर TV और गेम कंसोल इस तरह फ़ोन का इंटरनेट इस्तेमाल नहीं कर पाते। ऐप में Other (TV, game console…) दबाएं। फिर भी आज़माना हो तो Try anyway दबाएं, डिवाइस पर दिखे Wi-Fi से जुड़ें, और अगर उसकी नेटवर्क सेटिंग में प्रॉक्सी का विकल्प हो तो दो वैल्यू डालें। नहीं तो Choose another device दबाएं और उसकी जगह कोई फ़ोन, टैबलेट या कंप्यूटर जोड़ें।

अब भी कनेक्ट नहीं हुआ?

ऐप की कनेक्ट स्क्रीन पर Still not connected? दबाएं और चुनें कि दूसरे डिवाइस पर क्या दिख रहा है:

  • I can't see the Wi-Fi name (Wi-Fi का नाम नहीं दिख रहा): फ़ोन की स्क्रीन ऑन रखें और उसे डिवाइस के पास लाएं, फिर Wi-Fi लिस्ट रिफ़्रेश करें। तब भी न दिखे तो डिवाइस इस तरह का Wi-Fi नहीं देख पाता: इसकी जगह फ़ोन का अपना हॉटस्पॉट इस्तेमाल करें (ऊपर देखें)।
  • Wi-Fi says "No internet" (Wi-Fi "No internet" दिखा रहा है): यह सामान्य है। उसी से जुड़े रहें और स्टेप पूरे करें।
  • The setup file doesn't connect (सेटअप फ़ाइल कनेक्ट नहीं होती, Windows): पक्का करें कि विंडो में ऐप में दिखे IP और पोर्ट हैं, फ़ोन पर शेयरिंग और मोबाइल डेटा चालू रखें, फिर विंडो बंद करें और डेस्कटॉप पर TLU connect पर डबल-क्लिक करें।
  • Firefox says the proxy server is refusing connections (Firefox कहता है प्रॉक्सी सर्वर कनेक्शन मना कर रहा है): दोनों वैल्यू (SOCKS Host और Port) जांचें और पक्का करें कि फ़ोन पर शेयरिंग अब भी चालू है।
  • Firefox works, other apps don't (Firefox चलता है, बाकी ऐप्स नहीं): ऐसा ही होना है। फ़ोन का इंटरनेट सिर्फ़ Firefox इस्तेमाल करता है। सभी ऐप्स के लिए sing-box इस्तेमाल करें (ऊपर देखें)।
  • Websites don't open (वेबसाइटें नहीं खुलतीं; iPhone, Mac, दूसरे डिवाइस): दोनों वैल्यू जांचें, पक्का करें कि फ़ोन पर मोबाइल डेटा और शेयरिंग चालू हैं, और डिवाइस पर कोई दूसरा VPN ऐप हो तो बंद करें।

Android-to-Android आसान है

अगर दोनों डिवाइस Android हैं, तो शेयर करने वाले फ़ोन पर Android phone or tablet दबाएं। ऐप पूछता है Is Tether Link Utility on the other phone?

  • Yes, it's installed: QR कोड तुरंत दिखता है।
  • No, but it has internet: दूसरे फ़ोन पर कैमरा खोलें, दिखे कोड पर रखें, आने वाले लिंक पर टैप करें, फिर Install।
  • No, and it has no internet: शेयर करने वाला फ़ोन ऐप भेज सकता है। दोनों फ़ोन पर Play Store खोलें, ऊपर दाईं तरफ़ अपनी प्रोफ़ाइल फ़ोटो पर टैप करें, फिर Manage apps & device और Share। शेयर करने वाले फ़ोन पर Send और दूसरे पर Receive दबाएं, Tether Link Utility पर टिक करें, भेजने वाला तीर दबाएं, फिर दूसरे फ़ोन पर Install दबाएं।

फिर दूसरे फ़ोन पर Tether Link Utility खोलें, Use another phone's internet दबाएं, Scan QR code दबाएं और कैमरा कोड पर रखें। पूछे तो Connect दबाएं। स्टेप-बाय-स्टेप: QR कोड से Android से Android पर मोबाइल डेटा शेयर करें।

अगर आप अपने फ़ोन का मोबाइल डेटा लैपटॉप या दूसरे फ़ोन के साथ शेयर करना चाहते हैं, तो Tether Link Utility एक Android ऐप है जो यह काम एक लोकल SOCKS5 प्रॉक्सी के ज़रिए करता है। कनेक्टेड डिवाइस का डेटा फिर भी आपके मोबाइल प्लान में गिना जाता है, इसलिए अपने कैरियर की टेदरिंग शर्तें ज़रूर देखें।

Tether Link Utility

एक Android ऐप जो आपके फ़ोन का मोबाइल डेटा आपके दूसरे डिवाइसों के साथ एक लोकल SOCKS5 प्रॉक्सी के ज़रिए शेयर करता है। न root, न अकाउंट, न रिमोट सर्वर।
