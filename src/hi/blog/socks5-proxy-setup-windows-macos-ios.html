Windows, macOS और iOS पर SOCKS5 प्रॉक्सी कैसे सेट करें

प्रकाशित 18 सितंबर, 2026 · अपडेट 15 अक्टूबर, 2026

Tether Link Utility आपके Android फ़ोन पर एक लोकल SOCKS5 प्रॉक्सी चलाता है। SOCKS5 प्रॉक्सी सेटिंग सपोर्ट करने वाला कोई भी डिवाइस फ़ोन के Wi-Fi (Android का LocalOnlyHotspot) से जुड़कर इस प्रॉक्सी से कनेक्ट हो सकता है, Windows या macOS पर किसी अलग क्लाइंट ऐप की ज़रूरत नहीं, और iOS पर एक हल्का सा। यहां हर प्लेटफ़ॉर्म को इससे जोड़ने का तरीका बताया गया है।

शुरू करने से पहले

इसी क्रम में करें। हो सकता है फ़ोन के Wi-Fi पर अपना इंटरनेट न हो (वह सिर्फ़ फ़ोन के प्रॉक्सी तक पहुंचाता है), इसलिए पहले सब कुछ इंस्टॉल कर लें।

  1. पहले ज़रूरी चीज़ें इंस्टॉल करें, जब तक आपके डिवाइस पर उसका सामान्य इंटरनेट चल रहा है:
    • iPhone या iPad: App Store से Shadowrocket या Potatso Lite।
    • कंप्यूटर: Firefox, या Chrome/Edge के लिए FoxyProxy एक्सटेंशन।
    • Mac, सभी ऐप्स: हमारी स्क्रिप्ट अभी एक बार चलाएं ताकि वह sing-box इंस्टॉल कर दे (देखें macOS)।
    • Windows या Linux, सभी ऐप्स: sing-box अभी डाउनलोड करें (देखें Windows या Linux)।
  2. फ़ोन पर Tether Link Utility खोलें और START दबाएं।
  3. इसके बाद ऐप में Wi-Fi के नीचे दिखे नेटवर्क से, Password के नीचे दिखे पासवर्ड के साथ जुड़ें (ये Show QR code स्क्रीन पर QR के नीचे भी लिखे होते हैं)। यह Wi-Fi "No internet" दिखा सकता है; यह सामान्य है।
  4. ऐप में दिखाए गए IP एड्रेस और पोर्ट नोट करें। नीचे के सेटअप में दोनों डालने होंगे।

पोर्ट के बारे में: ऐप पोर्ट को सेव रखता है, इसलिए हर डिवाइस पर इसे सिर्फ़ एक बार डालना होता है। पोर्ट तभी बदलता है जब फ़ोन का कोई दूसरा ऐप उसे इस्तेमाल करने लगे, और ऐसा होने पर ऐप आपको बताता है। अपना पोर्ट चुनने के लिए Port वाली लाइन पर Edit दबाएं और 1024 से 65535 के बीच कोई नंबर डालें (1024 से 32767 के बीच टकराव की संभावना कम होती है)। चुना गया पोर्ट खाली हो तो वह आपके लिए तब तक रिज़र्व रहता है जब तक कोई दूसरा ऐप उसे इस्तेमाल न करने लगे।

फ़ोन का अपना हॉटस्पॉट इस्तेमाल करना

अगर ऐप के बजाय आप फ़ोन का सिस्टम हॉटस्पॉट खुद ऑन करते हैं (Android पर Mobile Hotspot, iPhone पर Personal Hotspot), तो ऐप में Add hotspot Wi-Fi details पर टैप करें और हॉटस्पॉट का नाम और पासवर्ड एक बार सेव करें। ये सिर्फ़ आपके डिवाइस पर स्टोर होते हैं और ऐप आपका हॉटस्पॉट नहीं बदलता। ये डिटेल्स QR कोड में जोड़ दी जाती हैं, ताकि दूसरे डिवाइस उसे स्कैन करके नेटवर्क से जुड़ सकें। iPhone पर पासवर्ड Settings > Personal Hotspot में मिलता है। जब Android ऐप अपने आप अपना हॉटस्पॉट शुरू करता है, तब आप यह स्टेप छोड़ सकते हैं।

Windows

विकल्प A: Firefox (किसी एक्सटेंशन की ज़रूरत नहीं)

  1. Settings → General → Network Settings → Settings पर जाएं।
  2. Manual proxy configuration चुनें।
  3. फ़ोन का IP SOCKS Host में डालें, पोर्ट Port में, और SOCKS v5 चुनें।
  4. Proxy DNS when using SOCKS v5 चेक करें, ताकि DNS लुकअप भी प्रॉक्सी से जाएं।

विकल्प B: Chrome या Edge, FoxyProxy के ज़रिए

  1. Chrome Web Store से FoxyProxy एक्सटेंशन इंस्टॉल करें।
  2. एक नया प्रॉक्सी जोड़ें: टाइप SOCKS5, host = फ़ोन का IP, port = ऐप में दिखाया गया पोर्ट।
  3. टूलबार आइकन से FoxyProxy को उस प्रॉक्सी पर स्विच करें।

विकल्प C (सुझाया गया): sing-box से सभी ऐप्स के लिए

Firefox और FoxyProxy सिर्फ उस एक ब्राउज़र का ट्रैफ़िक प्रॉक्सी से भेजते हैं, बाकी ऐप्स और DNS लुकअप नहीं। Windows पर हर ऐप और DNS को प्रॉक्सी से भेजने के लिए इसके बजाय sing-box (ओपन सोर्स, MIT-जैसा लाइसेंस, सक्रिय रूप से मेंटेन्ड) को TUN मोड में इस्तेमाल करें:

  1. github.com/SagerNet/sing-box/releases से लेटेस्ट Windows रिलीज़ डाउनलोड करें, फ़ोन के Wi-Fi से जुड़ने से पहले।
  2. नीचे दिया कॉन्फ़िग config.json के तौर पर सेव करें, IP/पोर्ट को ऐप में दिखाए गए से बदल दें।
  3. एक एलिवेटेड (Administrator) टर्मिनल से चलाएं: sing-box run --config config.json

macOS

विकल्प A: native Network सेटिंग्स

  1. System Settings → Network खोलें।
  2. जिस Wi-Fi नेटवर्क से जुड़े हैं (जो फ़ोन प्रसारित कर रहा है) उसे चुनें और Details… दबाएं।
  3. Proxies पर जाएं, SOCKS Proxy चेक करें।
  4. फ़ोन का IP एड्रेस और पोर्ट डालें, फिर OK → Apply दबाएं।

किसी थर्ड-पार्टी ऐप की ज़रूरत नहीं, पर ध्यान दें macOS की native SOCKS सेटिंग DNS को प्रॉक्सी से रूट नहीं करती, इसलिए DNS क्वेरी प्रॉक्सी के बजाय सीधे जा सकती हैं, और कुछ ऐप्स सिस्टम प्रॉक्सी सेटिंग को नहीं मानते। DNS सहित पूरी कवरेज के लिए विकल्प B वाली स्क्रिप्ट इस्तेमाल करें।

विकल्प B (सुझाया गया): sing-box से सभी ऐप्स के लिए

हर चीज़, हर ऐप, DNS सहित, के लिए ऊपर वाली native सेटिंग के बजाय sing-box को TUN मोड में चलाएं।

सबसे आसान तरीका: हमारी wrapper स्क्रिप्ट डाउनलोड करें और फ़ोन के Wi-Fi से जुड़ने से पहले उसे एक बार चलाएं, ताकि वह आपके सामान्य इंटरनेट से sing-box इंस्टॉल कर सके। यह Homebrew चेक करती है, ज़रूरत पड़ने पर sing-box इंस्टॉल करती है (इंटरनेट न हो तो साफ़ मैसेज के साथ रुक जाती है), आपके फ़ोन का IP और पोर्ट पूछती है, और सब कुछ बैकग्राउंड में चलाती है (Terminal विंडो मिनिमाइज़ हो जाती है और सिर्फ कुछ गड़बड़ होने पर वापस आती है)।

tlu-mac-tunnel.zip डाउनलोड करें

इसे अनज़िप करें, फिर Terminal में: chmod +x tlu-mac-tunnel.sh && ./tlu-mac-tunnel.sh

यह स्क्रिप्ट TLU के लिए तैयार किया गया sing-box सेटअप है। अगर आप sing-box जानते हैं, तो उसे सीधे इस्तेमाल कर सकते हैं।

इसे काम करते हुए देखें

Mac पर स्क्रिप्ट चलते हुए: फ़ोन अपना मोबाइल डेटा शेयर करता है, कनेक्शन के ज़रिए 1GB की टेस्ट फ़ाइल डाउनलोड होती है, और ऐप का काउंटर फ़ोन से होकर गया ट्रैफ़िक दिखाता है।

या इसे हाथ से सेटअप करें:

  1. फ़ोन के Wi-Fi से जुड़ने से पहले Homebrew से इंस्टॉल करें: brew install sing-box
  2. नीचे दिया कॉन्फ़िग ~/config.json के तौर पर सेव करें, IP/पोर्ट को ऐप में दिखाए गए से बदल दें।
  3. इसे चलाएं (sudo चाहिए, यह एक वर्चुअल नेटवर्क इंटरफ़ेस बनाता है और राउटिंग बदलता है): sudo sing-box run --config ~/config.json
  4. अगर विकल्प A वाली native SOCKS Proxy सेटिंग ऑन थी तो उसे बंद कर दें, sing-box का TUN मोड इसे पूरी तरह बदल देता है।

sing-box कॉन्फ़िग (Windows, macOS और Linux के लिए काम करता है, बस IP/पोर्ट बदलें)। interface_name खाली छोड़ दें ताकि यह अपने आप एक उपलब्ध इंटरफ़ेस चुन ले:

{
  "dns": {
    "servers": [
      { "type": "udp", "tag": "remote", "server": "8.8.8.8", "detour": "phone-socks5" },
      { "type": "local", "tag": "local", "detour": "direct" }
    ],
    "final": "remote"
  },
  "inbounds": [
    { "type": "tun", "tag": "tun-in", "address": ["172.19.0.1/30"], "mtu": 1500,
      "auto_route": true, "strict_route": true, "stack": "system" }
  ],
  "outbounds": [
    { "type": "socks", "tag": "phone-socks5", "server": "PHONE_IP", "server_port": PHONE_PORT, "version": "5" },
    { "type": "direct", "tag": "direct" }
  ],
  "route": {
    "rules": [ { "ip_cidr": ["PHONE_IP/32"], "outbound": "direct" } ],
    "final": "phone-socks5",
    "auto_detect_interface": true,
    "default_domain_resolver": "remote"
  }
}

PHONE_IP और PHONE_PORT दोनों को ऐप में दिखाए गए वैल्यू से बदलें (और PHONE_IP/32 रूट रूल भी, यह लाइन टनल को अपने ही फ़ोन कनेक्शन को खुद के ज़रिए रूट करने से रोकती है)। ऐप के लेटेस्ट वर्शन में SOCKS5 UDP ASSOCIATE सपोर्ट है, इसलिए QUIC/HTTP3 और DNS भी प्रॉक्सी से जाते हैं।

Linux

विकल्प A: Firefox

  1. Settings → General → Network Settings → Settings पर जाएं और Manual proxy configuration चुनें।
  2. फ़ोन का IP SOCKS Host में डालें, पोर्ट Port में, और SOCKS v5 चुनें।
  3. Proxy DNS when using SOCKS v5 चेक करें।

विकल्प B: sing-box से सभी ऐप्स के लिए

  1. फ़ोन के Wi-Fi से जुड़ने से पहले sing-box अपने डिस्ट्रीब्यूशन के पैकेज से या GitHub releases से इंस्टॉल करें।
  2. ऊपर दिया कॉन्फ़िग config.json के तौर पर सेव करें, IP/पोर्ट को ऐप में दिखाए गए से बदल दें।
  3. root के तौर पर चलाएं: sudo sing-box run --config config.json

iOS

विकल्प A: Shadowrocket (पेड, एक बार की खरीद)

  1. Shadowrocket खोलें और ऊपर दाईं तरफ़ + बटन दबाएं।
  2. टाइप Socks5 चुनें।
  3. फ़ोन का IP एड्रेस के तौर पर और ऐप में दिखाया गया पोर्ट डालें।
  4. सेव करें, फिर कनेक्ट करने के लिए ऊपर टॉगल दबाएं।

विकल्प B: Potatso Lite (फ्री)

  1. Potatso Lite खोलें और एक नई प्रॉक्सी प्रोफ़ाइल जोड़ें।
  2. SOCKS5 चुनें, IP और पोर्ट डालें, और सेव करें।
  3. iOS के पूछने पर VPN प्रोफ़ाइल इनेबल करें, यही तरीका है जिससे Potatso ट्रैफ़िक को SOCKS5 प्रॉक्सी से रूट करता है, क्योंकि iOS में macOS जैसी native SOCKS5 सेटिंग नहीं होती।

DNS टिप: पक्का करें कि DNS क्वेरी भी प्रॉक्सी से जाएं। Firefox में Proxy DNS when using SOCKS v5 चेक करें; Shadowrocket यह डिफ़ॉल्ट रूप से करता है। macOS की System Settings वाली SOCKS सेटिंग DNS को प्रॉक्सी से नहीं भेजती, इसलिए Mac पर पूरी कवरेज के लिए हमारी स्क्रिप्ट इस्तेमाल करें। ऊपर बताया गया sing-box का TUN मोड यह अपने आप संभालता है, क्योंकि यह हर ऐप की सेटिंग पर निर्भर रहने के बजाय बाकी ट्रैफ़िक के साथ DNS भी प्रॉक्सी से भेजता है।

Android-to-Android आसान है

अगर दोनों डिवाइस Android हैं, ऊपर का सब कुछ छोड़ें, दूसरे फ़ोन पर Tether Link Utility खोलें, Use another phone's internet चुनें, Scan QR code दबाएं और कैमरा शेयर करने वाले फ़ोन पर दिखाए गए QR कोड पर रखें। QR कोड में फ़ोन के Wi-Fi की डिटेल्स और प्रॉक्सी एड्रेस दोनों होते हैं। Android 10+ पर ऐप सिस्टम के ज़रिए Wi-Fi से जुड़ता है (सिस्टम पुष्टि मांग सकता है), फिर Android के VpnService से डिवाइस का ट्रैफ़िक प्रॉक्सी से भेजता है। किसी रिमोट सर्वर का इस्तेमाल नहीं होता।

अगर आप अपने फ़ोन का मोबाइल डेटा लैपटॉप या दूसरे फ़ोन के साथ शेयर करना चाहते हैं, तो Tether Link Utility एक Android ऐप है जो यह काम एक लोकल SOCKS5 प्रॉक्सी के ज़रिए करता है। कनेक्टेड डिवाइस का डेटा फिर भी आपके मोबाइल प्लान में गिना जाता है, इसलिए अपने कैरियर की टेदरिंग शर्तें ज़रूर देखें।

कनेक्ट नहीं हो रहा? हमें बताएं आप कहां अटके। हम हर मैसेज पढ़ते हैं।

Tether Link Utility

एक Android ऐप जो आपके फ़ोन का मोबाइल डेटा आपके दूसरे डिवाइसों के साथ एक लोकल SOCKS5 प्रॉक्सी के ज़रिए शेयर करता है। न root, न अकाउंट, न रिमोट सर्वर।
