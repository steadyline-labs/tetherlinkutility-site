How to Set Up a SOCKS5 Proxy on Windows, macOS & iOS

Published September 18, 2026 · Updated October 22, 2026

Tether Link Utility runs a local SOCKS5 proxy on your Android phone. Any device that supports SOCKS5 proxy settings can use it over the Wi-Fi network the app creates: no separate client app is needed on Windows or macOS, and a lightweight one is needed on iOS. Here is how to set up each platform.

Before you start

Do these in this order. The phone's Wi-Fi may have no internet of its own (it only reaches the proxy on the phone), so install everything first.

  1. Install what you need first, while your device still has its normal internet:
    • iPhone or iPad: Potatso (free) or Shadowrocket (paid) from the App Store.
    • Windows or Linux computer: Firefox from firefox.com, or the FoxyProxy extension for Chrome or Edge.
    • Mac: nothing for the built-in setting. For all apps, run our script once now so it installs sing-box (see macOS).
    • Windows or Linux, all apps: download sing-box now (see Windows or Linux).

    No internet on that device? Connect it to any other Wi-Fi for a few minutes (home, work, café) and install from there. A Windows computer can also get Firefox by cable: on the phone, download Firefox for Windows, connect the phone to the computer with a USB cable, copy the file to the computer and open it.

  2. On the sharing phone, open Tether Link Utility and tap START SHARING. The first time, the app says One permission is needed: tap Allow, then OK in the phone's Connection request window.
  3. The app asks Which device will use this phone's internet? Tap yours: Android phone or tablet, Windows computer, iPhone or iPad, Mac, Linux or Other (TV, game console…).
  4. Next it asks whether the device already has what it needs, for example Is Firefox on the computer? Tap Yes, No, but it has internet or No, and it has no internet, and the app shows how to install it. Don't join the phone's Wi-Fi yet.
  5. Then, on your device, join the Wi-Fi the app shows under Name, with the Password shown. If it says "No internet", that's normal.
  6. Enter the two values the app shows (SOCKS Host or Server, and Port) as described below for your device. The app's screen waits by itself and moves on when the device connects.

About the port: the app saves the port, so you only enter it once on each device. It changes only if another app on the phone takes it, and the app warns you when that happens. To pick your own, tap Edit on the Port row and enter a number between 1024 and 65535 (1024 to 32767 is less likely to clash). If that port is free, it stays reserved for you until another app starts using it.

Using your phone's own hotspot

If you turn on your phone's system hotspot yourself (Mobile Hotspot on Android, Personal Hotspot on iPhone) instead of letting the app start one, tap Add hotspot Wi-Fi details in the app and save the hotspot's name and password once. They are stored only on your device and the app doesn't change your hotspot. The details are added to the QR code, so other devices can join the network by scanning it. On iPhone, the password is in Settings > Personal Hotspot. When the Android app starts its own hotspot automatically, you can skip this.

Windows

Option A: Firefox (no extension needed)

  1. In Firefox, open Settings, type proxy in the search box at the top and click Configure proxy.
  2. Choose Manual proxy configuration.
  3. Enter the phone's IP under SOCKS Host, the port under Port, and select SOCKS v5.
  4. Tick Proxy DNS when using SOCKS v5 so DNS lookups also go through the proxy, then click OK.
  5. Open any website in Firefox. Only Firefox uses the phone's internet; other apps on the computer don't.

Option B: Chrome or Edge, via FoxyProxy

  1. Install the FoxyProxy extension from the Chrome Web Store.
  2. Add a new proxy: type SOCKS5, host = phone's IP, port = the port shown in the app.
  3. Switch FoxyProxy to that proxy from its toolbar icon.

Option C (recommended): all apps with sing-box

Firefox and FoxyProxy only send that one browser's traffic through the proxy. To route every app on Windows through it, DNS included, use sing-box (open source, actively maintained) in TUN mode:

  1. Before joining the phone's Wi-Fi, download the latest Windows release from github.com/SagerNet/sing-box/releases.
  2. Save the config below as config.json, replacing the IP and port with the values shown in the app.
  3. Run it from an elevated (Administrator) terminal: sing-box run --config config.json

macOS

Option A: built-in proxy setting

  1. Open System Settings → Wi-Fi.
  2. Click Details… next to the phone's Wi-Fi, then Proxies.
  3. Turn on SOCKS proxy, enter the phone's IP address and port, then click OK.
  4. Open any website in Safari.

No third-party app is needed. Note that this macOS setting does not send DNS lookups through the proxy, and apps which ignore the system proxy setting are not covered either. For full coverage, DNS included, use the script in Option B.

Option B (recommended): all apps with sing-box

To route every app through the proxy, DNS included, run sing-box in TUN mode instead of the native setting above.

Easiest way: download our wrapper script and run it once before joining the phone's Wi-Fi, so it can install sing-box over your normal internet. It checks for Homebrew, installs sing-box if needed (and stops with a clear message if there is no internet), asks for your phone's IP and port, and runs everything in the background (the Terminal window minimizes and comes back only if something goes wrong).

Unzip it, then in Terminal: chmod +x tlu-mac-tunnel.sh && ./tlu-mac-tunnel.sh

Or set it up by hand:

  1. Before joining the phone's Wi-Fi, install via Homebrew: brew install sing-box
  2. Save the config below as ~/config.json, replacing the IP and port with the values shown in the app.
  3. Run it (it needs sudo because it creates a virtual network interface and changes routing): sudo sing-box run --config ~/config.json
  4. Turn off the native SOCKS Proxy setting from Option A if you had it on; sing-box's TUN mode replaces it.

sing-box config (works on Windows, macOS and Linux, just swap the IP and port). Leave interface_name unset so it picks an available interface automatically:

{
  "dns": {
    "servers": [
      { "type": "udp", "tag": "remote", "server": "8.8.8.8", "detour": "phone-socks5" },
      { "type": "local", "tag": "local", "detour": "direct" }
    ],
    "final": "remote"
  },
  "inbounds": [
    { "type": "tun", "tag": "tun-in", "address": ["172.19.0.1/30"], "mtu": 1500,
      "auto_route": true, "strict_route": true, "stack": "system" }
  ],
  "outbounds": [
    { "type": "socks", "tag": "phone-socks5", "server": "PHONE_IP", "server_port": PHONE_PORT, "version": "5" },
    { "type": "direct", "tag": "direct" }
  ],
  "route": {
    "rules": [ { "ip_cidr": ["PHONE_IP/32"], "outbound": "direct" } ],
    "final": "phone-socks5",
    "auto_detect_interface": true,
    "default_domain_resolver": "remote"
  }
}

Replace both PHONE_IP and PHONE_PORT with the values shown in the app, including the PHONE_IP/32 route rule. That rule sends the connection to the phone itself directly instead of looping it back into the tunnel. The app supports SOCKS5 UDP ASSOCIATE, so DNS and QUIC/HTTP3 traffic can also use the proxy.

Linux

Option A: Firefox

  1. In Firefox, open Settings, type proxy in the search box, click Configure proxy and choose Manual proxy configuration.
  2. Enter the phone's IP under SOCKS Host, the port under Port, and select SOCKS v5.
  3. Tick Proxy DNS when using SOCKS v5 and click OK.

Option B: all apps with sing-box

  1. Before joining the phone's Wi-Fi, install sing-box from your distribution's packages or the GitHub releases.
  2. Save the config above as config.json, replacing the IP and port with the values shown in the app.
  3. Run it as root: sudo sing-box run --config config.json

iOS

Option A: Potatso (free)

  1. Open Potatso and tap +.
  2. Add a SOCKS5 server with the two values from the app (Server and Port) and save.
  3. Turn on the switch in Potatso. If the iPhone asks, tap Allow. This is how Potatso sends traffic to the SOCKS5 proxy, since iOS has no system-wide SOCKS5 setting like macOS does.

Option B: Shadowrocket (paid, one-time purchase)

  1. Open Shadowrocket and tap the + button in the top right.
  2. Choose type Socks5.
  3. Enter the phone's IP as the address and the port shown in the app.
  4. Save, then tap the toggle at the top to connect.

DNS tip: let DNS lookups go through the proxy as well. In Firefox, tick Proxy DNS when using SOCKS v5; Shadowrocket does this by default. The macOS System Settings SOCKS proxy does not send DNS through the proxy, so on a Mac use our script for full coverage. sing-box's TUN mode handles DNS for every app automatically.

TVs and game consoles

Most TVs and game consoles can't use the phone's internet this way. In the app, tap Other (TV, game console…). To try anyway, tap Try anyway, join the Wi-Fi shown on the device, and if its network settings have a proxy option, enter the two values. Otherwise tap Choose another device and connect a phone, tablet or computer instead.

Still not connected?

On the app's connect screen, tap Still not connected? and pick what you see on the other device:

  • I can't see the Wi-Fi name: keep the phone's screen on and close to the device, then refresh the Wi-Fi list. If it still isn't there, the device can't see this kind of Wi-Fi: use your phone's own hotspot instead (see above).
  • Wi-Fi says "No internet": that's normal. Stay on it and finish the steps.
  • Firefox says the proxy server is refusing connections: check the two values (SOCKS Host and Port) and make sure sharing is still on on the phone.
  • Firefox works, other apps don't: that's expected. Only Firefox uses the phone's internet. For all apps, use sing-box (see above).
  • Websites don't open (iPhone, Mac, other devices): check the two values, make sure mobile data and sharing are on on the phone, and turn off any other VPN app on the device.

Android to Android is simpler

If both devices are Android, tap Android phone or tablet on the sharing phone. The app asks Is Tether Link Utility on the other phone?

  • Yes, it's installed: the QR code appears right away.
  • No, but it has internet: open the camera on the other phone, point it at the code shown, tap the link that appears, then Install.
  • No, and it has no internet: the sharing phone can send the app. On both phones, open Play Store, tap your profile picture at the top right, then Manage apps & device and Share. Tap Send on the sharing phone and Receive on the other, tick Tether Link Utility, tap the send arrow, then Install on the other phone.

Then, on the other phone, open Tether Link Utility, tap Use another phone's internet, tap Scan QR code and point the camera at the code. If it asks, tap Connect. Step by step: Share Mobile Data From Android to Android With a QR Code.

Data used by connected devices counts toward the server phone's mobile plan, so check your carrier's tethering terms.
