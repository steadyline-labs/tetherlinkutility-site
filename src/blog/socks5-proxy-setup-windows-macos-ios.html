How to Set Up a SOCKS5 Proxy on Windows, macOS & iOS

Published September 18, 2026 · Updated October 31, 2026

Tether Link Utility runs a local SOCKS5 proxy on your Android phone. Other devices use it over the Wi-Fi network the app creates. On a Windows PC or a Mac, one small file sets up every app for you: it installs and runs sing-box, so the whole computer uses the phone's internet. On a phone or tablet (Android, iPhone or iPad), you install Tether Link Utility and scan the QR code: nothing to set up by hand. Here is how to set up each platform.

Before you start

Do these in this order. The phone's Wi-Fi may have no internet of its own (it only reaches the proxy on the phone), so install everything first.

  1. Install what you need first, while your device still has its normal internet:
    • Android phone or tablet, iPhone or iPad: Tether Link Utility from Google Play or the App Store. That's all a phone or tablet needs.
    • Windows computer: the setup file (see Windows). It installs and runs sing-box for you, so every app works.
    • Linux computer: sing-box for every app (see Linux), or Firefox from firefox.com for that browser only.
    • Mac: our script (see macOS). It installs and runs sing-box for you, through the phone too if needed.

    No internet on that device? Connect it to any other Wi-Fi for a few minutes (home, work, café) and download from there. A Windows PC can also get the setup file from the phone: download it on the phone and send it to the PC by Bluetooth or USB cable.

  2. On the sharing phone, open Tether Link Utility and tap START SHARING. The first time, the app says One permission is needed: tap Allow, then OK in the phone's Connection request window.
  3. The app asks Which device will use this phone's internet? Tap yours: Android phone or tablet, Windows computer, iPhone or iPad, Mac, Linux or Other (TV, game console…).
  4. For a Windows PC or a Mac, the app first shows the file to download. For a phone or other devices, it asks whether the device already has what it needs, for example Is Tether Link Utility on the other phone? Tap Yes, it's installed, No, but it has internet or No, and it has no internet, and the app shows how to install it. Don't join the phone's Wi-Fi yet.
  5. Then, on your device, join the Wi-Fi the app shows under Name, with the Password shown. If it says "No internet", that's normal.
  6. Enter the two values the app shows (SOCKS Host or Server, and Port) as described below for your device. The app's screen waits by itself and moves on when the device connects.

Phone or tablet? Install Tether Link Utility on it (Google Play or the App Store), open it, tap Use another phone's internet, then Scan QR code. It joins the Wi-Fi by itself and there are no values to type. Details: iPhone and iPad.

About the port: the app saves the port, so you only enter it once on each device. It changes only if another app on the phone takes it, and the app warns you when that happens. To pick your own, tap Edit on the Port row and enter a number between 1024 and 65535 (1024 to 32767 is less likely to clash). If that port is free, it stays reserved for you until another app starts using it.

Using your phone's own hotspot

If you turn on your phone's system hotspot yourself (Mobile Hotspot on Android, Personal Hotspot on iPhone) instead of letting the app start one, tap Add hotspot Wi-Fi details in the app and save the hotspot's name and password once. They are stored only on your device and the app doesn't change your hotspot. The details are added to the QR code, so other devices can join the network by scanning it. On iPhone, the password is in Settings > Personal Hotspot. When the Android app starts its own hotspot automatically, you can skip this.

Windows

Recommended: the setup file (every app)

One small file does the whole setup for every app on the PC, DNS included. It asks for the IP and port shown in the app, checks that the phone answers, downloads sing-box once from its official GitHub page (checked with a SHA256 hash) and connects.

Download TLU-Windows-Setup.cmd

  1. Download the file above while the PC still has its own internet. If Edge says the file could harm your device, click Keep under the file name. Don't see it? Click the download arrow at the top right of Edge. No internet on the PC to download it? Download the file on the phone and send it to the PC by Bluetooth or USB cable.
  2. Join the phone's Wi-Fi and turn sharing on in the app.
  3. Double-click the file. If Windows asks Are you sure you want to run this software?, click Run. If it shows Windows protected your PC instead, click More info, then Run anyway. Click Yes when Windows asks to allow changes (it names Windows PowerShell, that is this file).
  4. Press Enter to use the suggested IP (or type the one in the app), then type the port.
  5. When you see Connected. Keep this window open., you're done. Close the window to stop. Next time, double-click TLU connect on the desktop.

The file is plain text: you can open it in Notepad and read every step. It sends nothing anywhere. Prefer to do it by hand? Follow the steps below.

Don't use Windows Settings > Proxy. It won't work with this app. Use one of the options below.

By hand: all apps with sing-box

The setup file above does these steps for you. To do them by hand, use sing-box (open source, actively maintained) in TUN mode:

  1. Open github.com/SagerNet/sing-box/releases while your PC still has internet. Download the file that ends in windows-amd64.zip (Snapdragon or Surface Pro X: windows-arm64.zip). Right-click it, choose Extract All, then Extract.
  2. Open Notepad and paste the config text from the sing-box config box below. Replace PHONE_IP (it appears twice) and PHONE_PORT with the numbers shown in the app. Click File, Save as. Open the sing-box folder (the one with sing-box.exe inside), set Save as type to All files, name it config.json, click Save.
  3. Right-click the Start button and choose Terminal (Admin). Click Yes.
  4. In the window, type cd and a space. Drag the sing-box folder from File Explorer into the window, then press Enter. If nothing appears when you drag: right-click the sing-box folder, choose Copy as path, click in the window, press Ctrl+V, then Enter.
  5. Type .\sing-box.exe run --config config.json and press Enter. Leave this window open.
  6. Wait until you see sing-box started. Lines will keep scrolling; that's normal.

Browser only: Firefox (no extension needed)

  1. In Firefox, open Settings, type proxy in the search box at the top and click Configure proxy.
  2. Choose Manual proxy configuration.
  3. Enter the phone's IP under SOCKS Host, the port under Port, and select SOCKS v5.
  4. Tick Proxy DNS when using SOCKS v5 so DNS lookups also go through the proxy, then click OK.
  5. Open any website in Firefox. Only Firefox uses the phone's internet; other apps on the computer don't.

Browser only: Chrome or Edge, via FoxyProxy

  1. Install the FoxyProxy extension from the Chrome Web Store.
  2. Add a new proxy: type SOCKS5, host = phone's IP, port = the port shown in the app.
  3. Switch FoxyProxy to that proxy from its toolbar icon.

macOS

Recommended: all apps with our script (sing-box)

Our script installs and runs sing-box for you in TUN mode, so every app, DNS included, uses the phone's internet.

Easiest way: download our script

Nothing else to install: Homebrew is not needed. The first time, the script downloads sing-box from its official GitHub page (checked with a SHA256 hash), through the phone if the Mac has no internet of its own. It asks for the IP and port shown in the app and keeps running in the background (the Terminal window minimizes and comes back only if something goes wrong).

Download tlu-mac-tunnel.zip

  1. Safari opens the zip for you. If you see a .zip, double-click it. The tlu-mac-tunnel folder appears in Downloads.
  2. Join the phone's Wi-Fi and turn sharing on in the app.
  3. Press Command + Space, type Terminal, press Return.
  4. Type cd ~/Downloads/tlu-mac-tunnel and press Return.
  5. Type bash tlu-mac-tunnel.sh and press Return.
  6. Type the IP and the port shown in the app, pressing Return after each. Next time it asks Connect to IP:port? (y/n): type y and press Return to use the same ones, or n to type new ones.
  7. Type your Mac password and press Return. Nothing appears while you type it; that's normal.
  8. When you see Connected., you're done. The window minimizes and the connection keeps running.

To stop: click Terminal in the Dock, then press Control + C in its window. Stop it here first, before you turn sharing off in the app; otherwise the Mac has no internet until you stop it.

The script is plain text: you can open it in TextEdit and read every step. It sends nothing anywhere. It is a sing-box setup tuned for TLU; if you know sing-box, you can use it directly.

Or set it up by hand:

  1. While the Mac still has internet, open github.com/SagerNet/sing-box/releases and download the file that ends in darwin-arm64.tar.gz (Mac with an Apple chip, M1 or newer) or darwin-amd64.tar.gz (Intel Mac). Double-click it in Downloads to unpack it. (Already use Homebrew? brew install sing-box works too.)
  2. Open TextEdit and first click Format › Make Plain Text (otherwise the file won't work). Paste the text from the sing-box config box below and replace PHONE_IP (it appears twice) and PHONE_PORT with the numbers shown in the app. Click File › Save, name it config.json, choose the sing-box folder (the one with sing-box inside) and click Save. If TextEdit asks, click Use .json.
  3. Press Command + Space, type Terminal, press Return. Type cd and a space, drag the sing-box folder into the window, then press Return.
  4. Type xattr -c sing-box and press Return (this lets macOS run the file you downloaded). Then type sudo ./sing-box run --config config.json and press Return (with Homebrew: sudo sing-box run --config config.json). Type your Mac password and press Return; nothing appears while you type it.
  5. Wait until you see sing-box started and leave the window open. To stop, press Control + C in this window, before you turn sharing off in the app.
  6. Turn off the built-in SOCKS proxy setting (see below) if you had it on; sing-box's TUN mode replaces it.

Other way: built-in proxy setting (fewer apps)

  1. Open System Settings → Wi-Fi.
  2. Click Details… next to the phone's Wi-Fi, then Proxies.
  3. Turn on SOCKS proxy, enter the phone's IP address and port, then click OK.
  4. Open any website in Safari.

No third-party app is needed, but this macOS setting does not send DNS lookups through the proxy, and apps which ignore the system proxy setting are not covered either. For full coverage, DNS included, use the script above.

sing-box config (works on Windows, macOS and Linux, just swap the IP and port). Leave interface_name unset so it picks an available interface automatically:

{
  "dns": {
    "servers": [
      { "type": "udp", "tag": "remote", "server": "8.8.8.8", "detour": "phone-socks5" },
      { "type": "local", "tag": "local", "detour": "direct" }
    ],
    "final": "remote"
  },
  "inbounds": [
    { "type": "tun", "tag": "tun-in", "address": ["172.19.0.1/30"], "mtu": 1500,
      "auto_route": true, "strict_route": true, "stack": "system" }
  ],
  "outbounds": [
    { "type": "socks", "tag": "phone-socks5", "server": "PHONE_IP", "server_port": PHONE_PORT, "version": "5" },
    { "type": "direct", "tag": "direct" }
  ],
  "route": {
    "rules": [ { "ip_cidr": ["PHONE_IP/32"], "outbound": "direct" } ],
    "final": "phone-socks5",
    "auto_detect_interface": true,
    "default_domain_resolver": "remote"
  }
}

Replace both PHONE_IP and PHONE_PORT with the values shown in the app, including the PHONE_IP/32 route rule. That rule sends the connection to the phone itself directly instead of looping it back into the tunnel. The app supports SOCKS5 UDP ASSOCIATE, so DNS and QUIC/HTTP3 traffic can also use the proxy.

Linux

Option A: Firefox

  1. In Firefox, open Settings, type proxy in the search box, click Configure proxy and choose Manual proxy configuration.
  2. Enter the phone's IP under SOCKS Host, the port under Port, and select SOCKS v5.
  3. Tick Proxy DNS when using SOCKS v5 and click OK.

Option B: all apps with sing-box

  1. Before joining the phone's Wi-Fi, install sing-box from your distribution's packages or the GitHub releases.
  2. Save the config above as config.json, replacing the IP and port with the values shown in the app.
  3. Run it as root: sudo sing-box run --config config.json

iPhone and iPad

Phones and tablets don't need any settings. Install Tether Link Utility on the iPhone or iPad and scan the QR code, just like on Android.

  1. While the iPhone still has its normal internet, install Tether Link Utility from the App Store.
  2. On the sharing phone, tap iPhone or iPad. The app asks Is Tether Link Utility on the iPhone? If it isn't yet, the app shows a code: open the camera on the iPhone, point it at the code, tap the link that appears, then Get.
  3. On the iPhone, open Tether Link Utility and tap Use another phone's internet.
  4. Tap Scan QR code and point the camera at the code on the sharing phone. If it asks, tap Join or Connect. It joins the Wi-Fi by itself.

Don't type the two values into the proxy option of the iPhone's Wi-Fi settings: that option won't work with this app. Use the app instead.

DNS tip: let DNS lookups go through the proxy as well. In Firefox, tick Proxy DNS when using SOCKS v5. The macOS System Settings SOCKS proxy does not send DNS through the proxy, so on a Mac use our script for full coverage. sing-box's TUN mode handles DNS for every app automatically.

TVs and game consoles

Most TVs and game consoles can't use the phone's internet this way. In the app, tap Other (TV, game console…). To try anyway, tap Try anyway, join the Wi-Fi shown on the device, and if its network settings have a proxy option, enter the two values. Otherwise tap Choose another device and connect a phone, tablet or computer instead.

Still not connected?

On the app's connect screen, tap Still not connected? and pick what you see on the other device:

  • A phone or tablet connects, but nothing loads: install Tether Link Utility on it and scan the QR code. The proxy option in a phone's Wi-Fi settings won't work with this app.
  • I can't see the Wi-Fi name: keep the phone's screen on and close to the device, then refresh the Wi-Fi list, or add the network by hand with the name and password shown in the app. If it still isn't there, the device can't see this kind of Wi-Fi: use your phone's own hotspot instead (see above).
  • Wi-Fi says "No internet": that's normal. Stay on it and finish the steps.
  • The setup file doesn't connect (Windows): make sure the window shows the IP and port shown in the app, keep sharing and mobile data on on the phone, then close the window and double-click TLU connect on the desktop.
  • Firefox says the proxy server is refusing connections: check the two values (SOCKS Host and Port) and make sure sharing is still on on the phone.
  • Firefox works, other apps don't: that's expected. Only Firefox uses the phone's internet. For all apps, use sing-box (see above).
  • Websites don't open (Mac, other devices): check the two values, make sure mobile data and sharing are on on the phone, and turn off any other VPN app on the device.

Android to Android is simpler

If both devices are Android, tap Android phone or tablet on the sharing phone. The app asks Is Tether Link Utility on the other phone?

  • Yes, it's installed: the QR code appears right away.
  • No, but it has internet: open the camera on the other phone, point it at the code shown, tap the link that appears, then Install.
  • No, and it has no internet: the sharing phone can send the app. On both phones, open Play Store, tap your profile picture at the top right, then Manage apps & device and Share. Tap Send on the sharing phone and Receive on the other, tick Tether Link Utility, tap the send arrow, then Install on the other phone.

Then, on the other phone, open Tether Link Utility, tap Use another phone's internet, tap Scan QR code and point the camera at the code. If it asks, tap Connect. Step by step: Share Mobile Data From Android to Android With a QR Code.

Data used by connected devices counts toward the server phone's mobile plan, so check your carrier's tethering terms.
