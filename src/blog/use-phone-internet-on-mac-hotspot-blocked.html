Hotspot Blocked? Use Your Phone's Internet on a Mac (2026)

Published November 11, 2026

Short answer: install Tether Link Utility on your Android phone, tap START SHARING, join the phone's Wi-Fi from the Mac and run our script. The Mac then uses your phone's mobile data for every app, without the phone's built-in hotspot. No root, free for 1 device. Data still comes from your plan, and results can vary by carrier.

Before you start

  • An Android phone with mobile data.
  • A Mac that can join a Wi-Fi network.
  • The script, tlu-mac-tunnel.zip. Download it while the Mac still has internet, or on the phone and send it over by Bluetooth or cable.

The steps

  1. Start sharing on the phone Open Tether Link Utility and tap START SHARING.
  2. Choose Computer When the app asks which device will use the phone's internet, tap Computer, TV or other.
  3. Join the phone's Wi-Fi on the Mac Pick the network name shown in the app and type the password shown. The Mac may say there is no internet. That is normal for now.
  4. Open the script folder Double-click the downloaded zip so the tlu-mac-tunnel folder appears in Downloads. Open Terminal, type cd ~/Downloads/tlu-mac-tunnel and press Return.
  5. Run the script and type the numbers Type bash tlu-mac-tunnel.sh and press Return. When it asks, enter the phone's IP address, the port shown in the app and your Mac password. More detail is in the Mac section of the full guide.
  6. Wait for the connected message When the script says the connection is up, you are online. Keep the window open while you work.

What this does and does not do. It does not create extra data. Everything the other device uses still comes out of your mobile plan, and your carrier's terms for sharing data still apply. What changes is how the data is shared: through a local proxy on your phone instead of the phone's built-in hotspot feature. Results can vary by carrier and plan.

If something does not work

  • Still no internet: check the app still says sharing and shows your Mac as connected, then run the script again.
  • Browser only: the full guide also covers using a single browser with the proxy.
