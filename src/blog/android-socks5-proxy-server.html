Android SOCKS5 Proxy: Set Up a Proxy Server on Your Phone

Published September 25, 2026 · Updated October 31, 2026

Short answer: to run a SOCKS5 proxy on Android, install an app that acts as a SOCKS5 server, start it, and connect your other devices to the phone's Wi-Fi using the IP address and port it shows. Android's own Wi-Fi proxy setting only supports HTTP proxies, so an Android phone that should use a SOCKS5 proxy needs an app as well.

A SOCKS5 proxy server is usually something that runs on a computer or in a data center. It can also run on an Android phone, and that turns out to be a practical way to share the phone's mobile data with other devices on the same Wi-Fi network. This guide explains what SOCKS5 is, why you might run it on a phone, how it works together with Android's local hotspot, and how to connect each type of device.

What is SOCKS5?

SOCKS5 is a general-purpose proxy protocol. A client (a browser, an app, or a system-wide tool) connects to the proxy and asks it to open a connection to some address on its behalf. The proxy makes that connection and passes data back and forth. SOCKS5 works for any TCP connection, and it also supports UDP through a feature called UDP ASSOCIATE, which is used by DNS and by some newer protocols such as QUIC.

Unlike an HTTP proxy, SOCKS5 doesn't need to understand the traffic it carries. That makes it a good fit for sharing a connection: websites, games, messaging apps and file transfers can all go through it.

Why run a SOCKS5 proxy on a phone?

  • Share mobile data with other devices. A laptop, tablet or second phone on the same Wi-Fi network can send its traffic to the proxy, and the phone forwards it over its mobile data connection.
  • Works with many clients. Browsers, operating systems and many apps already support SOCKS5, so desktops often need no extra app.
  • Everything stays local. The proxy runs on your phone. Traffic goes from your device to the phone and out through its mobile connection, without a remote server in between.
  • No root required. A regular Android app can run a SOCKS5 server.

How it works with LocalOnlyHotspot

Other devices need a network path to the phone. Tether Link Utility gets that path from Android's LocalOnlyHotspot feature (available since Android 8): the system creates a Wi-Fi network with a generated name and password. On its own, a LocalOnlyHotspot gives connected devices access to the phone but not to the internet. The SOCKS5 proxy fills that gap: devices on the local Wi-Fi connect to the proxy's IP address and port, and the proxy forwards their connections over the phone's mobile data.

In the app, tap START SHARING, then tap the device you want to connect. For a Windows PC or a Mac, it first shows the setup file or script to download; for other devices, it asks whether the device already has what it needs. Only then does it show the Wi-Fi details. Then it shows one connect screen: a QR code with both the Wi-Fi details and the proxy address for another Android phone, or the Wi-Fi name, password and the two values (IP address and port) for other devices. The screen waits by itself until the device connects.

Connecting clients

First, every client joins the phone's Wi-Fi network. Then it needs to be told to use the proxy:

  • Android: install Tether Link Utility on the other phone too and scan the QR code. On Android 10 and newer it joins the Wi-Fi automatically, then routes the phone's traffic through the proxy with Android's VpnService (a local VPN interface, no remote server). See Share Mobile Data From Android to Android With a QR Code.
  • Windows: download the setup file while the PC still has internet, join the phone's Wi-Fi and double-click it. It installs and runs sing-box for you, so every app on the PC, DNS included, uses the phone's internet. Firefox or FoxyProxy also work, for that one browser only. Windows steps.
  • macOS: download our script while the Mac still has internet, join the phone's Wi-Fi and run it in Terminal. It installs and runs sing-box for you, so every app, DNS included, uses the phone's internet. The built-in proxy setting in System Settings covers fewer apps. Mac steps.
  • Linux: run sing-box in TUN mode for every app (see the Linux steps), or set the SOCKS5 proxy in Firefox for that browser only.
  • iPhone and iPad: install Tether Link Utility from the App Store, tap Use another phone's internet and scan the QR code. No proxy settings needed.

Step-by-step instructions for each platform, including a sing-box configuration file, are in How to Set Up a SOCKS5 Proxy on Windows, macOS & iOS.

Security notes

  • Local network only. The proxy listens on the phone's local hotspot network. Only devices that have joined that Wi-Fi network can reach it, so share the Wi-Fi password (and the QR code, which contains it) only with people you trust.
  • SOCKS5 doesn't encrypt. The protocol forwards traffic but doesn't encrypt it. Your Wi-Fi link to the phone is protected by the hotspot's WPA2 or WPA3 security, and beyond the phone your traffic is as protected as the sites and apps you use make it. Prefer HTTPS sites and apps that use encrypted connections.
  • Stop the server when you're done. Stopping it closes the hotspot and the proxy.

Limits and costs

The free version of Tether Link Utility allows 1 connected device at a time and shows ads. Pro allows up to 5 devices without ads. All data used by connected devices comes from the phone's mobile plan and counts toward it, and carriers set their own tethering rules, so check your plan's terms before sharing a lot of data.
