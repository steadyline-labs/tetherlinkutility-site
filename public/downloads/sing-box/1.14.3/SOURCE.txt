sing-box 1.14.3, unmodified copies of the official release files

These files are exact copies of the sing-box 1.14.3 release files published by
the sing-box project. They are kept here only as a second download location
for the Tether Link Utility desktop scripts, which check every file against the
SHA256 hashes in SHA256SUMS (the same hashes as the official release).
Tether Link Utility is not part of the sing-box project and is not endorsed by it.
